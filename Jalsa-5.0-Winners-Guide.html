Recording Results

A short guide for whoever is putting winners on the board. Setting up takes about two minutes and is only needed once per phone. After that a result takes under a minute.

What is in this guide

  1. Setting up your phone, once
  2. Recording a result
  3. Fixing a mistake
  4. Before you photograph anyone
  5. If something goes wrong

Setting up your phone

You do this once. The board remembers it, so from then on publishing is a single tap. You will need two things sent to you privately: the username and password, and the settings file with its passphrase.

1

Open the winners board

Tap the link sent in the team group, then choose the Winners tab at the top of the page.

Screenshot to addscreens/01-winners-tab.pngThe three tabs at the top, with Winners selected.
2

Tap Record results

It sits just above the list of events. Everyone in the society can see this board; only signed-in organisers can change it.

Screenshot to addscreens/02-record-results.pngThe Record results button.
3

Sign in

Enter the username and password shared with you privately. They are the same for the whole organising team.

The board now shows name boxes and photo buttons on every card.

Screenshot to addscreens/03-sign-in.pngThe sign-in box asking for username and password.
4

Open Publish and find Quick setuponce only

Tap Publish. The first section is Quick setup.

Type the passphrase you were given, then tap Load from file and pick the settings file from the group.

On an iPhone the file picker can be awkward. If so, tap Paste text instead, paste the block from the chat, and tap Load pasted text.

Screenshot to addscreens/04-publish-dialog.pngThe Publish dialog, showing Quick setup at the top.
5

Check it loadedonce only

You should see a green line naming the repository. That is the whole setup done — this device will remember it, so you will not be asked again.

Delete the settings file from your phone now. You no longer need it.

Screenshot to addscreens/05-loaded.pngThe green confirmation after the settings file has loaded.

Recording a result

Do this as each event finishes, while the names are still fresh.

6

Find the event

Use the search box and type the event name, for example skating. Each age group and each Singles or Doubles category has its own card.

Check the category on the card before you type. It is easy to put a result on the wrong age group.

Screenshot to addscreens/06-find-event.pngThe search box with an event found below it.
7

Type the winners' names

Gold is first place, Silver is second.

  • Normal events: one name in each.
  • Doubles: two names in Gold and two in Silver.
  • Team events: the team name, and the members if you have them.

Spell the name the way the participant did on the registration form, so it matches the rest of the records.

Screenshot to addscreens/07-enter-names.pngA Gold and Silver card with the name boxes visible.
8

Add the photos

Tap Add photo and either take one or choose one from your gallery. It is shrunk automatically, so there is no need to resize anything first.

Photos are optional. A result with names and no photo is perfectly fine.

Screenshot to addscreens/08-add-photo.pngThe Add photo button and a chosen photo.
9

Doubles have four photo slots

Two Gold winners and two Silver winners, so four slots. Each one is labelled with the player's name once you have typed it.

Type the names first, then add the photos — that way the labels tell you which slot is whose.

Screenshot to addscreens/09-doubles.pngA Doubles card showing all four photo slots.
10

Publish

Tap Publish. After the one-time setup this is a single tap, with nothing to fill in.

Photos upload first, then the results. Leave the page open until it finishes.

Screenshot to addscreens/10-publish.pngThe Publish button.
11

Confirm it went up

You will get a confirmation saying it was published. The live site catches up within about a minute.

Reload the page and you should see your result. If you do not, publish again — nothing breaks by publishing twice.

Screenshot to addscreens/11-published.pngThe 'Published to GitHub' confirmation.

Fixing a mistake

Everything can be changed after publishing. Nothing is final.

12

Change a name

Type over it and tap Publish again.

13

Replace or remove a photo

Change photo swaps it. remove takes it away entirely, and the old file is deleted from the repository when you publish.

14

Clear a whole result

Clear this result at the bottom of the card wipes the names and the photos for that one event. It asks first.

Nothing is actually changed for anyone else until you Publish.

Screenshot to addscreens/12-clear.pngThe Clear this result button on a card.

Before you photograph anyone

The winners board is on a public website. Anyone with the link can see the photos, and once published they are difficult to remove completely.

  • Ask a parent first before photographing a child. If the parent is not there, skip the photo.
  • If anyone would rather not be photographed, record just the name. A result without a photo is completely normal.
  • Photograph the winner holding their medal, not the crowd. Avoid catching other children in the background.
  • Never photograph anything with a flat number, a phone number or a registration sheet visible.

If something goes wrong

Nothing here is urgent. A result recorded late is not a problem; a wrong result published confidently is.

What you seeWhat to do
Nothing happens when I tap Record resultsYou are probably signed in already. Look for the name boxes on the cards — if they are there, you can start typing.
It says the passphrase is wrongCheck for a capital letter or a trailing space. The passphrase is not the same as the board password. If it still fails, ask for the file to be sent again — a part-copied file gives the same message.
It says the settings text is incompleteOnly part of the block was copied. Make sure you have everything from BEGIN to END, then paste it again.
403 or “not accessible by personal access token”The saved token has expired or lost its permission. Tell whoever set up the settings file — they need to issue a new one. Nothing you can fix on your phone.
404 or “not found”Same thing: the settings need re-issuing. Do not retype anything by hand.
The photo will not uploadVery large photos from some cameras can fail. Take a normal photo rather than a RAW or Live Photo, or publish the names first and add the photo afterwards.
I published to the wrong eventOpen the correct card, enter the result there, then use Clear this result on the wrong one, and publish once.
Someone else is publishing at the same timeWait for them to finish, reload the page, then make your change. Two people publishing at the same moment can overwrite one another.

Two things to keep to yourself

  • The board password and the settings passphrase. Do not put either in the residents' group.
  • The settings file. Delete it from your phone once you have loaded it — it does not need to stay in your downloads.
